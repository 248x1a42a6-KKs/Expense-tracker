# Paisa Pulse 

**Topic:** Expense tracker
Track daily spending, set a monthly budget and get a warning when you are close
to it (80%) or over it.

## Screens
1. Home: spending this month, budget card, list of expenses (loading, error with Retry, empty, data)
2. Detail: full information about one expense, with delete
3. Add expense: validated form
4. Summary: totals per category

## Data source
Dart, using Flutter

## Run the project
```
flutter pub get
dart run flutter_launcher_icons
flutter test
flutter run
flutter build apk --release
```
APK: build/app/outputs/flutter-apk/app-release.apk
